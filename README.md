📊 README – Dashboard Excel Interactif (Ventes Europe Ouest 2023)

🚀 Présentation du projet

Ce projet est un tableau de bord interactif développé sous Excel, permettant d’analyser les performances commerciales en Europe de l’Ouest pour l’année 2023.

L’objectif est de proposer une solution simple, visuelle et dynamique pour :

Suivre les ventes 📈

Analyser les performances par pays 🌍

Mesurer les KPIs clés 💡

Faciliter la prise de décision
